Visualizador experimental sem georreferenciamento. Não usar para navegação real.

Importar cartas náuticas

Selecione arquivos PNG, JPG, WebP ou ZIP contendo imagens. É possível selecionar vários arquivos de uma vez.

Arquivos KAP/BSB, GeoTIFF e PDF não são interpretados nesta versão. ZIPs contendo apenas esses formatos não serão exibidos. A carta é apresentada como imagem, sem coordenadas ou posição GPS.
